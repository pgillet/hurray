Hurray is an open project. Contributions — spec feedback, implementation work, cookbook
recipes, and tutorials — are welcome.

## Contributing

- Read the [specification](/docs/stable/) and the implementation requirements before
  proposing changes.
- Open an issue on [GitHub](https://github.com/pgillet/hurray) to discuss a change before
  sending a large pull request.
- Spec changes go through the amendment process: a decision is recorded as an
  **Architecture Decision Record** (ADR) before the normative text changes. Browse the
  [ADR appendix](/docs/stable/adr/ADR-001-private-extension-type-descriptors.html) in the
  docs.
- Every implementation change ships with tests, documentation, and a cookbook example.

## Code of conduct

All participants are expected to uphold a respectful, harassment-free environment. Be kind,
assume good faith, and critique ideas rather than people. A full code of conduct will be
published here; until then, these principles apply.

## Governance

Hurray is currently maintained by its core contributors, who steward the specification and
the reference implementation. Design decisions are made in the open and recorded as ADRs.
A formal governance model will be documented here as the project grows.

## Mailing lists

Project mailing lists are not yet established. For now, discussion happens on
[GitHub issues and pull requests](https://github.com/pgillet/hurray). This section will be
updated when lists are available.
